# Data

The datasets used in this project are not included in the repository due to file size.

## Source

Traffic crash data was obtained from the City of Chicago Traffic Crashes – Crashes dataset through the Chicago Data Portal and Socrata Open Data API.

Dataset ID: `85ca-t3if`

Data used in the analysis covers reported crashes from January 1, 2021 through December 31, 2025.

[City of Chicago Traffic Crashes Dataset](https://data.cityofchicago.org/Transportation/Traffic-Crashes-Crashes/85ca-t3if)

## Local Files

The analysis uses the following files locally:

- `chicago_traffic_crashes_2021_2025.csv` — raw downloaded dataset
- `chicago_traffic_crashes_clean.csv` — cleaned analytical dataset

These CSV files are excluded from version control through `.gitignore`.
